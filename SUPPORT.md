# Support

## Documentation

Start with the [documentation index](docs/README.md). It has reading paths for product,
engineering, operations and research readers.

## Questions and bugs

Use [GitHub Issues](https://github.com/michaelatamuk/laix/issues) for:

- reproducible bugs;
- documentation gaps;
- feature requests;
- integration questions that are not security-sensitive.

Include the version, package (Python or TypeScript), a minimal reproduction and the expected
behaviour.

## Security

Do not open a public issue for a vulnerability. Follow [SECURITY.md](SECURITY.md).

## Conduct

Participation is covered by [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## Contributions

The workflow, setup and checks are in [CONTRIBUTING.md](CONTRIBUTING.md).

## Service level

LAIX is a pre-1.0 project maintained on a best-effort basis. There is no guaranteed response
time, support contract or security SLA.
