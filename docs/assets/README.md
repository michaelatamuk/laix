## Regenerate

```powershell
python -m pip install -r scripts/docs/requirements-assets.txt
python scripts/docs/render_assets.py
python scripts/docs/render_overview_svgs.py
```

The first script writes every PNG in this folder. The second writes the two overview SVGs and uses
only the standard library. Both are development-only and are not part of the runtime dependencies or
CI. The benchmark and ablation charts use matplotlib with a light background and are generated from
the committed result JSON, not hand-drawn. The SVGs are committed so GitHub renders them without a
build step.

## GitHub social preview

1. Open the repository on GitHub.
2. Go to **Settings** -> **General** -> **Social preview**.
3. Upload `docs/assets/banner.png`.
4. Check the preview at 1280 x 640.

GitHub recommends a 1280 x 640 image. Keep the important text inside the centre so a
cropped preview still reads.

## Editing

- The PNGs are generated by `scripts/docs/render_assets.py`; the overview SVGs are generated by
  `scripts/docs/render_overview_svgs.py`; `how-it-works.svg` is hand-authored.
- Change the palette or layout in the generator, not by editing a generated PNG or SVG.
- Keep one banner, one loop diagram and one chart set; extra variants drift.
- Re-run `python scripts/ci/check_docs_links.py` after changing README image paths.
