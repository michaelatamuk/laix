## Regenerate

```powershell
python -m pip install -r scripts/docs/requirements-assets.txt
python scripts/docs/render_assets.py
```

The script writes every PNG in this folder. It is development-only and is not part of the
runtime dependencies or CI.

## GitHub social preview

1. Open the repository on GitHub.
2. Go to **Settings** -> **General** -> **Social preview**.
3. Upload `docs/assets/banner.png`.
4. Check the preview at 1280 x 640.

GitHub recommends a 1280 x 640 image. Keep the important text inside the centre so a
cropped preview still reads.

## Demo GIF: still to produce

`demo-placeholder.png` marks the missing asset. A real recording would lift the README more
than any further copy edit.

Suggested recording:

- 20-30 seconds, 1200 x 675, under 5 MB, no audio;
- start with the one-line problem or the command;
- show one decision with its verb, reason and score;
- show the integrated example choosing the reversible, promise-keeping option;
- end on the architecture diagram or the banner.

Tools:

- **Windows:** ScreenToGif or OBS, export GIF or MP4.
- **Terminal:** `asciinema rec demo.cast`, then
  [agg](https://github.com/asciinema/agg) to export a GIF.

When ready:

1. Save the file as `docs/assets/demo.gif`.
2. Add it to `README.md` under a `## Demo` heading.
3. Delete `demo-placeholder.png` or keep it as a design note.

## Editing

- The PNGs are generated by `scripts/docs/render_assets.py`.
- Change the palette or layout there, not by editing a PNG.
- Keep one banner and one architecture diagram; extra variants drift.
- Re-run `python scripts/ci/check_docs_links.py` after changing README image paths.
