# Validation data

This directory holds the optional external validation materials for Phase 3. Nothing here is
required for the synthetic benchmark.

| Folder | Purpose |
|---|---|
| `incidents/` | real or replayed incident rows, the anonymised input and the analysis |
| `user-study/` | the 20-vignette study, its offline app and its exported results |

Both tracks are honest fallbacks: the repository ships the harness, not the data. Do not commit raw
participant or incident data.
